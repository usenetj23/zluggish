Mods

warning A mod is code written by somebody else that runs inside the Overlay with the session of whoever opens its window. Only an administrator can add, enable or remove mods, and a mod that changes after it was enabled is switched off until it is approved again.

Internet access is off for every mod until an administrator allows it: the windows of a mod then may load data, images and fonts from any web address. Scripts from other addresses stay blocked.

You are not an administrator: you can see the mods, not change them.

Mod store

The Sauce for Zwift mod store lists mods by their authors. The server reads the store directory and downloads a release only when you press Install; it checks the size and SHA-256 before it unpacks anything. An installed mod starts disabled.

The store's file server (mod-api.sauce.llc) is no longer online. Zluggish installs a store mod from the GitHub repository it lists, and mods that list none can be installed from a ZIP file (zip the mod folder that contains manifest.json).

Install from GitHub

Many mods live in a GitHub repository. Paste its link (for example https://github.com/owner/name, a branch or release page also works) or type owner/name; the server downloads that repository as a zip (nothing from the web page is run). The archive has no published checksum, so read what you are enabling: the mod stays disabled until you enable it.
