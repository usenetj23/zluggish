# Official Zwift uploads and Runalyze

## Official Zwift uploads

Official Zwift credentials are separate from your local password and from the profile import.

1. In the web app, go to **Profile → Import / Export → Import from Zwift**.
2. Save your official Zwift credentials.
3. Select the options that you want. Activity uploads and Zwift Click authentication are separate options.

The server keeps the credentials encrypted.

## Runalyze

The Runalyze integration uses the existing `storage/<local-player-id>/runalyze_token.txt` file of the user.
